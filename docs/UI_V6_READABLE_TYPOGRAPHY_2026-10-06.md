# UI V6 — Readable Typography Pass

This pass keeps the V5 reference-matched dashboard structure and increases visual readability at normal browser zoom.

Changes:
- Larger sidebar, header, toolbar, score-card, company-card, chart, filter, and table typography.
- Larger control heights and spacing without changing functional wiring.
- Larger OHLCV/EMA/current-value text and chart controls.
- Larger filter preview inputs and Top-200 table rows.
- Increased chart and company-card heights so the larger text does not feel cramped.
- Dedicated workspaces also receive a legibility floor for filter tables.
