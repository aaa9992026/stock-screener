# UI V14 — Premium Sidebar Redesign

This revision replaces the plain navigation rail with a more polished product-style sidebar while preserving all existing workspaces and behavior.

## Changes

- Rebuilt the brand block with a larger chart-mark logo and clearer product typography.
- Added a Workspace section label to improve navigation hierarchy.
- Replaced text glyph icons with consistent inline SVG icons.
- Added icon tiles, hover states, active-state depth, and directional affordance.
- Added a compact live market-data status card at the bottom.
- Reworked the help card into a smaller, cleaner footer panel.
- Increased desktop sidebar width to 228px and adjusted content offset accordingly.
- Preserved responsive mobile navigation behavior.
- No ranking, filter, backtesting, Excel, or provider logic was changed.
