# UI V9 — Top 200 Ranking correction

The Top 200 workspace is now table-first. The previous UI showed a large selected-stock chart before the ranking list, causing the actual ranking task to be hidden below the fold and squeezing company values into narrow columns.

Changes:
- Top 200 table is visible immediately after the score cards.
- Market, Sort By, Order and Refresh controls are grouped with the table.
- Selected stock details and chart are moved below the ranking list.
- Company values use a two-column stat grid to avoid ellipsis/truncation.
- RSI/MACD/ROC/ADX snapshot cards remain visible in the selected-stock detail.
- Duplicate internal Top-200 table is hidden; ranking weights and indicator configuration remain available below the selected-stock preview.
- Desktop and responsive layouts were rebalanced.
