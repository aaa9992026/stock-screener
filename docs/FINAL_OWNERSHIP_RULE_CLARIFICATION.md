# Final ownership rule clarification

Applied the client's latest ownership-ranking clarification without estimating unavailable source data.

- Promoter yearly trend: latest-year promoter holding > previous-year promoter holding.
- FII trend: latest-year FII holding > previous-year FII holding AND prior-quarter FII holding > second-prior-quarter FII holding.
- DII/MF trend: prior-quarter combined DII/MF holding > second-prior-quarter combined DII/MF holding.
- Existing factor weights and enable/disable controls remain customizable.
- If a required comparison point is unavailable from the Indian shareholding provider, that factor returns unavailable rather than being guessed.
