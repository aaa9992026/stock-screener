# UI V23 — Premium Command Bar

The Overview stock workflow toolbar was rebuilt after the latest UI review.

## Changes

- Replaced the old row of unrelated rectangular controls with one cohesive command surface.
- Added consistent SVG icons for market, symbol search, Search, Refresh and Excel export.
- Market and symbol fields now use softer input styling with clearer focus states.
- Search remains the primary action while Refresh is neutral and Export Excel is a restrained success action.
- Daily / Weekly / Monthly is now a compact segmented interval control with a clear selected state.
- Improved spacing, radii, hierarchy, hover states and responsive behavior.
- Search suggestions remain attached to the symbol field.
- No market-data, ranking, chart, Excel or backend behavior was changed.
