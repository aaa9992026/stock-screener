# UI V16 — Backtesting command bar redesign

The Backtesting workspace top area was rebuilt after UI review.

## Changes

- Removed the detached global market/symbol search strip from Backtesting.
- Replaced the oversized Strategy Lab hero with one compact Backtesting command card.
- Market, stock, search, history horizon, and Run Backtest now live in one aligned workflow row.
- Replaced the History dropdown with clear 5Y / 10Y / 15Y / 20Y segmented controls.
- Kept selected stock/company/market/status visible without large empty whitespace.
- Added small verified-data context chips instead of redundant large metadata blocks.
- Preserved the existing verified-provider-only backtesting behavior and all strategy calculations.
- Added responsive 2-column and 1-column layouts for narrower screens.

No scoring or backtesting formulas were changed by this UI-only revision.
