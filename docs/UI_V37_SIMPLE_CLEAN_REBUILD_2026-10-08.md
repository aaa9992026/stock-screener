# UI V37 — Simple Clean Rebuild

This revision intentionally reduces visual complexity instead of adding more decorative UI.

- One neutral visual system across Overview, Top 200 Ranking, Filters, Backtesting, Export/Excel and Settings.
- Removed score-card icons and multi-color score styling; score cards now use one brand accent.
- Removed decorative section labels, secondary helper copy and non-essential visual treatments from dense workspaces.
- Flattened cards, removed most shadows, reduced corner radii, and standardized borders.
- Simplified the command bar and timeframe control; secondary action icons are hidden.
- Simplified the selected-company area and momentum snapshot while preserving all values and actions.
- Simplified filter, table, backtesting, Excel and Settings surfaces while preserving functional controls.
- Sidebar helper/status cards are hidden because the same connection status already exists in the page header.
- Existing ranking formulas, API calls, market data, filters, chart logic, exports and backtesting behavior are unchanged.
