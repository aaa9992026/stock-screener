# UI V15 — Premium Backtesting Redesign

Backtesting workspace redesigned to improve clarity, spacing, hierarchy, and empty/error states while preserving the existing backtest functionality.

## UI changes
- New Strategy Lab hero with selected stock, exchange, requested period and history status.
- Integrated history selector and Run Backtest action.
- Clear verified-history/provider alert with Retry action on failure.
- Four balanced KPI cards: Verified History, Buy & Hold, Combined Strategy, Max Drawdown.
- Larger performance chart with explicit Buy & Hold / Combined legend.
- Dedicated polished empty state instead of a large blank box.
- Compact Strategy Rules panel with grouped methodology and verified-data note.
- Redesigned Strategy Performance comparison table.
- Responsive tablet/mobile layout.

## Data behavior
No backtesting formulas or provider fallback rules were changed by this UI-only redesign. Verified-history requirements remain unchanged.
