# UI V18 — Accessible readability rebuild

This revision makes the dashboard readable at normal browser zoom without removing functionality.

- 16px base typography and larger navigation/header/status elements.
- 14px toolbar controls and larger score cards.
- Balanced company/chart overview layout with readable company stats and 2x2 indicator cards.
- Larger OHLCV, EMA, BB, EPS, RS hover values while preserving dynamic chart behavior.
- Larger Fundamental/Technical/Ownership preview controls.
- Top-200 table increased to 11–12px text with taller rows and larger controls.
- Responsive breakpoints keep the same functions on smaller displays.
