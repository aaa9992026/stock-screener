# Company / ISIN UI polish

Visual-only refinement of the company identity card.

- Keeps long company names readable without colliding with symbol/ISIN metadata.
- Displays the ticker as a separate badge.
- Displays ISIN as a separate labeled badge.
- Adds responsive wrapping for tablet/mobile widths.
- Does not change identity lookup, ISIN values, filters, rankings, RS calculations, or backend data logic.
