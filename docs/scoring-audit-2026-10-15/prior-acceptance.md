## Repairs implemented

- Replaced full compact-history loads in progress and candidate selection with metadata-only projections. RS evaluation now streams compact histories and legacy OHLCV one symbol at a time, retaining return summaries instead of all expanded prices. The selected 5,000-stock cohort remains deterministically sorted.
- Sector Analysis decodes one constituent at a time. Synthetic 5,000-stock tests measured **30.44 MB RS / 7.91 MB sector** peak Python allocations, versus the previous need to retain all decoded histories. These measurements exclude process RSS, driver buffers and Railway overhead.
- Limited Yahoo download workers to four. Bounded live OHLCV cache to 64 entries / 50,000 observations and removed expired entries on writes.
- Partial provider refreshes merge by date and preserve already verified compact history. Empty responses do not overwrite valid observations. Persisted exponential retries, checkpoints and cohort dates remain intact.
- Removed automatic startup OHLCV truncation and automatic score-snapshot deletion. Startup reports storage pressure while retaining existing data. Storage capacity and any retention policy require deployment-owner review; there is no destructive migration in this patch.
- Enabled the existing bounded fundamental enrichment job in free-tier mode, defaulting to two successful updates per market per batch (at most eight attempted candidates per market). Existing cooldowns remain enforced. Scheduler status now exposes actual running / registered / next-run state rather than only environment flags.
- Coverage counts now recognize compact price observations and state their limited coverage basis. They no longer report zero stored price coverage simply because OHLCV is absent.
- Dashboard scoring can use the same verified live OHLCV fallback as technical detail. Peer scans do not trigger an unbounded live fetch.
- Removed premature Final ranking labels; added explicit ranked / returned / final-qualified counts. UI now retains snapshot timestamp/version from the response and displays evaluated-set counts without changing the layout.
- Fixed Excel sector scoring so missing components retain their configured denominator, matching API provisional arithmetic.
