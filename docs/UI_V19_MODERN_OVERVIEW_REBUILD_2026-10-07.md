# UI V19 — Modern Overview Rebuild

This pass replaces the V18 compressed Overview with a cleaner product-dashboard layout while preserving the existing stock screener logic.

## Changes
- Rebalanced selected-company + chart hero layout.
- Fixed mini-indicator cards so they stay inside the company card and do not bleed beneath/behind the chart.
- Removed internal chart-metric scrollbars and compressed helper rows.
- Reduced visual nesting/card-inside-card clutter.
- Kept OHLCV, EMA, Bollinger, EPS, RS, overlay toggles and live hover behavior.
- Reworked company stats into a readable 3-column summary grid.
- Reworked preview filters into shallower, cleaner cards.
- Improved Top-200 table density and sticky header.
- Kept all detailed editors/functions in their existing dedicated workspaces.
