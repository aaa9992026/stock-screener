# UI V31 — Shared Overview / Top 200 top area

The Overview and Top 200 Ranking workspaces now use one identical top shell.

- Same content width and page padding.
- Same custom market selector and market menu.
- Same stock search field and Search / Refresh / Export controls.
- Same Daily / Weekly / Monthly segmented control.
- Same five score-card geometry, typography, icon sizing, progress bars and spacing.
- Responsive behavior is shared so switching workspaces no longer shifts or resizes the top area.
- No ranking, market-data, filter, chart, Excel or backend logic changed.
